# bibone-website

美容整体サロン BI.BONE(美骨/びぼね)の公式サイト。

**現在は骨組みの段階です。公開していません。**
- GitHub Pages は有効にしていません
- 全ページに `noindex, nofollow` を入れています。公開するときに外します

## 最初に読むもの
このリポジトリは公開です。店の内部情報(MASTER・DECISIONS・NG表現リスト)は、非公開リポジトリ `bibone-ops-` の `source/` にあります。
- `source/BIBONE_MASTER.md`:BI.BONEの現時点の正解。ここに書いていないことは、サイトに書かない
- `source/BIBONE_DECISIONS.md`:決めたことと、却下した案
- `source/共通_NG表現リスト.md`:使わない表現。仮の文章でも守る

部屋番号など、外に出さない情報をこのリポジトリに書かないこと。

## 構成
| ファイル | ページ |
|---|---|
| index.html | トップ(縦に長い1ページ。2023年のnote LPの流れを引き継ぐ) |
| story.html | ストーリー |
| menu.html | メニュー・料金・回数券・ランニングセミナー |
| screen.html | 入口ページ「画面に映る自分へ」 |
| access.html | アクセス・予約 |

- 静的HTML/CSS。ビルド環境は使わない。ヘッダー・フッターは各HTMLに直接書いている(変更するときは全ページを直す)
- 姉妹ブランド SOLE.(sole-website)と同じ構成。`base.css` と `main.js` は流用
- 配色・フォントは未定。`assets/css/variables.css` に仮の無彩色を置いている。決まったら、このファイルだけ差し替える

## 【要確認】
未定の箇所は、黄色い背景の `【要確認:…】` で示しています。
`【要確認` で全文検索すると、すべて拾えます。公開前に、すべて埋めるか消すこと。

## 作業ルール
作業前に、現在のブランチがmainの最新から派生しているか確認し、そうでなければmain最新から新しいブランチを切ってから作業すること。
